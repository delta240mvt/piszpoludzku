# Katalog syntetycznych przykładów

**Ostatnia aktualizacja:** 2026-07-30
**Pochodzenie:** wszystkie przykłady są syntetyczne; opisują klasy sytuacji wykorzystane przy redakcji e-booka i analizie raportów. Nie cytują materiałów źródłowych.

## Przypadki strategiczne i narracyjne

| Id | Sytuacja syntetyczna | Reguła |
|---|---|---|
| `ebook-kontekst-zamiast-hasla` | Rada o nawyku nie działa, dopóki nie pokazuje konkretnej sytuacji i skutku. | Dodaj kontekst tylko z materiału autora. |
| `ebook-seria-przed-weryfikacja` | Autor przygotował długą serię, zanim sprawdził reakcję odbiorców. | Usuń moralizowanie; pokaż związek decyzji i skutku. |
| `ebook-biblioteka-problemow` | Treść jest zbiorem odpowiedzi na powtarzające się pytania. | Zachowaj użyteczną metaforę aktywa. |
| `ebook-problem-techniczny` | Odbiorca nie wie, jak wykonać pojedynczą czynność w narzędziu. | Tutorial prowadzi krok po kroku. |
| `ebook-problem-emocjonalny` | Odbiorca ma opór przed publikacją, choć zna technikę. | Nie dopisuj emocji; zachowaj dostarczone doświadczenie. |
| `ebook-platforma-do-osoby` | Wybór kanału wynika z odbiorcy, nie z mody. | Nie stereotypizuj wieku ani platformy. |
| `ebook-doswiadczenie-jako-zasob` | Dłuższa droga autora staje się źródłem wiarygodności. | Nie upiększaj biografii. |
| `ebook-biegun-surowy` | Materiał jest celowo bezpośredni i prosty. | Nie dodawaj produkcyjnych ozdobników. |
| `ebook-biegun-filmowy` | Materiał jest świadomie dopracowany wizualnie. | Nie uznawaj dopracowania za sztuczność. |
| `ebook-przypadkowy-srodek` | Forma ma przypadkowe dodatki bez funkcji. | Redaguj niespójność, nie sam poziom produkcji. |
| `ebook-obraz-tworcy` | Odbiorca ocenia osobę i otoczenie zanim usłyszy argument. | Nie obiecuj statusu ani nie zachęcaj do udawania. |
| `ebook-obraz-materialu` | Tytuł, podpis i wskazanie na ekranie kierują uwagę. | Redaguj mikrocopy pod funkcję. |
| `ebook-dowod-spoleczny` | Liczba obserwujących jest sygnałem, lecz nie dowodem jakości. | Zachowaj niuans. |
| `ebook-ochrona-uwagi` | Twórca oddziela czas reagowania od czasu głębokiej pracy. | Nie zamieniaj w uniwersalną receptę. |
| `ebook-nietypowe-polaczenie` | Dwie zwykłe kompetencje dają nietypowy punkt widzenia. | Nie twórz fałszywej wyjątkowości. |
| `ebook-fraktal-niszy` | Szeroki temat można zawężać przez perspektywę, nie przez porzucenie całości. | Zostaw działającą metaforę. |
| `ebook-trzy-czestotliwosci` | Autor, przekaz i rynek muszą być wzajemnie dopasowane. | Nie spłaszczaj modelu do sloganu. |
| `ebook-jeden-odbiorca` | Materiał jest pisany do konkretnej osoby, nie abstrakcyjnej masy. | Zachowaj pytania robocze. |
| `ebook-pokaz-potem-nazwij` | Tutorial najpierw pokazuje czynność, potem ją objaśnia. | Imperatywy są celowe. |
| `ebook-tytul-i-obnizenie-progu` | Główny tytuł zaciekawia, podtytuł obniża barierę wejścia. | Nie łącz funkcji w jeden slogan. |
| `ebook-opcja-zamiast-wyroku` | Odpowiedź na komentarz pokazuje możliwość zamiast oceny osoby. | Zachowaj autonomię odbiorcy. |
| `ebook-granica-relacji` | Uszczypliwość można odbić spokojnie, atak osobisty wymaga granicy. | Nie neutralizuj ochrony autora. |
| `ebook-wzrost-nieliniowy` | Wynik rośnie skokami po dłuższym plateau. | Nie dopisuj gwarancji sukcesu. |
| `ebook-akordeon-iteracji` | Mocny sygnał prowadzi do pogłębienia, słaby do diagnozy. | Zachowaj przyczynowość. |
| `ebook-ai-nie-zastepuje-doswiadczenia` | AI porządkuje dostarczony materiał, nie produkuje doświadczenia. | Nie przypisuj modelowi autorstwa. |

## Wzorce redakcyjne i kontrwzorce

| Id | Problem lub kontrprzykład | Właściwa reakcja |
|---|---|---|
| `gpt-koniec-rozdzialu-seria` | Kilka identycznych końcówek rozdziału. | Zróżnicuj tylko część końcówek. |
| `gpt-nie-x-lecz-y` | Seryjny kontrast binarny. | Zostaw najlepszy, resztę wyjaśnij prościej. |
| `gpt-abstrakt-bez-stawki` | Teza nie pokazuje sytuacji ani skutku. | Usuń pustą ramę lub poproś o przykład. |
| `gpt-imperatyw-seryjny` | Każdy akapit rozkazuje czytelnikowi. | Mieszaj rejestry, nie kasuj instrukcji. |
| `gpt-meta-zapowiedz` | Tekst zapowiada to, co zaraz zrobi. | Usuń zapowiedź, jeśli jest zbędna. |
| `gpt-framework-po-polsku` | Angielski termin nie wnosi precyzji. | Użyj polskiego odpowiednika albo objaśnienia. |
| `humanizacja-puste-wzmocnienie` | „Przełomowa”, „kluczowa”, „ważna” bez dowodu. | Doprecyzuj lub usuń. |
| `humanizacja-kalka-oferty` | Dosłowna kalka z angielskiego. | Udomów polskie zdanie. |
| `humanizacja-nielokalne-swieto` | Przykład nie pasuje do polskiego kontekstu. | Nie lokalizuj bez danych autora. |
| `humanizacja-trojka-rytmiczna` | Trzy krótkie hasła dla pozornej energii. | Sprawdź, czy anafora ma funkcję. |
| `humanizacja-nadmiar-emoji` | Emoji przykrywają rzeczowy sens. | Dostosuj do kanału i marki. |
| `humanizacja-fałszywy-cios` | Powtórzenia symulują dynamikę. | Zostaw tylko powtórzenie z funkcją. |
| `humanizacja-niepotwierdzony-procent` | Precyzyjna liczba bez źródła. | Oznacz do weryfikacji; nie poprawiaj liczbą. |
| `humanizacja-zrodlo-bez-pokrycia` | Cytat lub instytucja bez potwierdzenia. | Nie fabrykuj atrybucji. |
| `humanizacja-rowne-akapity` | Każdy akapit ma identyczny rytm. | Zmień strukturę wyłącznie tam, gdzie monotonia szkodzi. |

## Klasy z raportu o sygnałach AI

| Id | Klasa | Właściwa reakcja |
|---|---|---|
| `signs-nadmuchana-waznosc` | Nadawanie drobnej sprawie wielkiej historycznej rangi. | Przywróć proporcję. |
| `signs-puffery` | Ton promocyjny bez potwierdzenia. | Usuń pusty superlatyw. |
| `signs-nieokreslone-zrodla` | „Eksperci” lub „media” bez wskazania. | Oznacz lukę. |
| `signs-szeroki-trend-bez-danych` | Ogólny trend jako ozdobnik. | Usuń nieudowodnione połączenie. |
| `signs-nadete-slownictwo` | Słowo o wysokim tonie bez treści. | Nie oceniaj pojedynczego słowa; szukaj serii. |
| `signs-canned-odpowiedz` | Uprzejma odpowiedź pełna pustych formuł. | Zostaw uprzejmość, skróć automatyzm. |
| `signs-uszkodzony-markdown` | Kod Markdown lub szablon jest popsuty. | Zatrzymaj się i napraw integralność. |
| `signs-przypis-bez-zakresu` | Przypis nie wspiera zdania, po którym stoi. | Nie przenoś go w ciemno. |
| `signs-komentarz-szablonowy` | Komentarz brzmi jak gotowa odpowiedź. | Nazwij konkretną decyzję. |
| `signs-edit-summary` | Raport zmian mówi tylko „poprawiono jakość”. | Wymień co i dlaczego zmieniono. |

## Pełna mapa klas z raportu o sygnałach

Poniższa mapa zachowuje kompletność zakresu raportu bez kopiowania jego przykładów.

| Sekcja źródłowa | Syntetyczne klasy w katalogu | Zasada |
|---|---|---|
| treść | nadęta ważność, medialna notability, szeroki trend, wyzwania i przyszłość, promocyjność, pseudoatrybucja | Sprawdź dowód i proporcję. |
| język i gramatyka | modne przymiotniki, „służy jako”, nominalizacja, nienaturalny synonim, przymiotnikowa mgła | Nie poluj na pojedyncze słowo; redaguj serię i sens. |
| styl | tytułowe podsumowanie, idealna paralela, fałszywie neutralna puenta, listicle bez sceny | Zachowaj strukturę tylko wtedy, gdy ma funkcję. |
| komunikacja do użytkownika | automatyczne przywitanie, ogólne zapewnienie, deklaracja wiedzy, propozycja dalszej pomocy | Zostaw uprzejmość, usuń automatyzm. |
| markup | Markdown w niewłaściwym środowisku, nadmiar boldów, zły obraz, przypadkowy szablon | Chroń składnię i waliduj po zmianie. |
| cytowania i reference | nieistniejący przypis, przypis bez użycia, źródło poza zakresem tezy, fikcyjny link | Nie naprawiaj przez dopisanie źródła. |
| komentarze i summary edycji | szablonowy komentarz, deklaracja zgodności zamiast opisu zmiany | Raportuj konkretne działanie. |
| sygnały historyczne | dydaktyczny disclaimer, automatyczne podsumowanie, formuła „jako model” | Traktuj jako kontekst historyczny, nie regułę. |
| sygnały ludzkie i nieskuteczne | poprawna gramatyka, mieszany rejestr, formalność, pojedyncze przejście, nieudokumentowana treść | Nie uznawaj ich za podstawę redakcji. |
